# 🚀 Grishma Thakare — Personal Portfolio

A sleek, modern, high-performance personal portfolio website built for **Grishma Thakare**, Software Developer and B.Tech Computer Science Engineering student at ITM Skills University, Navi Mumbai.

---

## 🌟 Key Features

- **Responsive Hero Section**: Displays key engineering highlights, interactive project stats counter, and live status badge.
- **Glassmorphic Bento Grid About Me**: Highlights bio, tech tags, and academic achievements with portrait media framing.
- **Featured Projects Showcase**:
  - **Sahayak Navigator** — AI-powered voice navigation system for visually impaired users (Winner @ HackWithMumbai 2.0).
  - **Data Migration CLI Tool** — High-throughput PostgreSQL to AWS S3 migration utility with AES-256 encryption.
  - **BidForGood** — Real-time charity auction web platform with live websocket bidding and payment processing.
  - **MediCheck** — Smart drug interaction and contraindication checker for medical safety.
  - **SaferStrays** — Stray animal reporting and rescue dispatch portal driven by LLMs and n8n workflows.
- **Professional Experience Timeline**:
  - **Aneero** — Full-Stack Developer Intern (LangChain LLMs, Node.js microservices, PostgreSQL, Next.js).
  - **Desi Destiny** — Frontend Developer Intern (React.js, UI modularization, performance optimization).
  - **LetsUpgrade** — Web Development & SEO Intern (metadata architecture, search indexability).
- **Tech Stack Matrix**: 6 organized categories (Languages, Frontend, Backend & APIs, Databases, Cloud & DevOps, AI & Automation).
- **Achievements & Athletic Excellence**: Highlights hackathon victories and 6-year National Athletics sprint representation (3 Silver, 1 Bronze medals).
- **Contact Form & Quick Links**: Fast contact form with glowing focus states, social links, and downloadable CV resume link.

---

## 🛠️ Built With

- **HTML5 & CSS3**: Custom responsive styling, CSS variables, glassmorphism backdrop filters, and custom scrollbar.
- **Bootstrap 5**: Grid layout system and utility classes.
- **JavaScript (ES6+)**: Dynamic UI interactions, counter animations, and form validation.
- **GSAP (GreenSock Animation Platform)**: Smooth ScrollTrigger animations, SplitText, and custom motion easing.
- **AOS (Animate On Scroll)**: Element reveal animations with permanent visibility retention.
- **Phosphor Icons**: High-resolution developer vector icons.

## ⚡ Local Setup & Run

1. **Clone the repository**:
   ```bash
   git clone https://github.com/grishma-blip/grishma-portfolioo.git
   cd grishma-portfolioo
   ```

2. **Run locally using any static web server**:
   ```bash
   npx serve .
   ```
   Or open `index.html` directly in your browser.
